## About Me

I'm **David Kariuki**, usually **dk**, a Software Engineer with a strong interest in building systems that are reliable, understandable, and maintainable.

My work generally sits at the intersection of:

- Backend and API engineering
- Java and Spring-based systems
- Linux engineering and automation
- Distributed systems and integration
- Infrastructure and self-hosting
- Networking and virtualisation
- Fintech and platform engineering
- Developer tooling
- System architecture and technical documentation

I enjoy understanding systems beyond the application layer, from the code running a service to the infrastructure, network, storage, and operating systems supporting it.

# What I'm Working On

### Backend Engineering

Designing and building backend services primarily around **Java, Spring Boot, APIs, integrations, messaging, data persistence, security, and distributed application architecture**.

### Linux Engineering

Building reusable Linux tooling and automation through **LinuxEuphony**, including workstation provisioning, system utilities, infrastructure tools, and automation scripts.

### Homelab & Infrastructure

Building **loft**, my personal infrastructure environment for experimenting with production-style networking, virtualisation, storage, observability, resilience, and self-hosted services.

### Fintech Engineering

Exploring serious fintech product ideas, reusable financial technology components, research, and platform engineering through **Finvone**.

I like approaching systems as complete engineering environments rather than isolated applications.
